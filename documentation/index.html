Introduction to AVA

AI-native visual analytics, from question to insight.

AVA is a TypeScript framework for asking questions about data and turning the answers into visualizations. Use it through an Agent Skill, the JavaScript API, or the command line, with an execution engine that fits your environment.

↗Use with your agentInstall the Agent Skill and try a complete data analysis demo.↗Start buildingInstall AVA and run your first analysis in Node.js.⌘Build for the browserBring analytics into your frontend with the JavaScript engine.›_Use the command lineInspect datasets, execute queries, and render charts from your terminal.

The core workflow

Connect a data source, inspect its structure, ask a question, and optionally generate a chart.

Source→Analyze→Visualize
  • Understand your data. schema() describes tables and fields; profile() computes statistics without an LLM call.
  • Ask better questions. suggest() recommends questions using the schema and available profile.
  • Analyze in natural language. analyze() translates, executes, and summarizes a question using the selected strategy.
  • Control individual steps. Use translate() and query() separately, or recommend() and viz() for chart generation.
