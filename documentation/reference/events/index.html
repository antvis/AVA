API Reference

Events & lifecycle

Observe data loading, model work, query execution, and cleanup.

Listen to events

AVA extends the AntV event emitter. Listen with string event names; event constants are not re-exported by the public package entry points.

Each emitted event has type and data. End events can include a serialized error; receiving an end event alone does not imply success.

Listener parameters

These inherited methods are synchronous. on(), once(), and off() return the emitter.

MethodParameterTypeRequired / default
on(evt, callback, once?)evtstringRequired event name.
on(evt, callback, once?)callbackFunctionRequired listener; receives the emitted event.
on(evt, callback, once?)oncebooleanOptional; false; remove after one invocation when true.
once(evt, callback)evtstringRequired event name.
once(evt, callback)callbackFunctionRequired one-time listener.
off(evt?, callback?)evtstringOptional; omit to remove all listeners.
off(evt?, callback?)callbackFunctionOptional; omit to remove every listener for the event.
emit(evt, ...args)evtstringRequired event name to emit manually.
emit(evt, ...args)argsany[]Optional rest arguments passed to listeners.

emit() returns no value. getEvents() takes no parameters and returns the emitter's listener registry. Use off() with the same function reference that was passed to on() to remove a particular listener.

Lifecycle

source() creates the engine and loads data. It does not emit schema events. The first operation needing uncached structure emits schemastart / schemaend; imported and cached schema skip these events. Each profile() call computes statistics and emits profiling events; schema events occur inside them if discovery is needed.

Replacing a source disposes its engine and clears metadata. dispose() clears state even if engine cleanup fails. Await operations before switching sources.

Translation events can include query, attempt, and dsl; query events include the DSL or result. Reasoning events include the loop step and action.

Schema and profiling failures emit an end event with data.error and reject the method’s Promise.
