Dataset notes

  1. DataBench. 1,789 questions across 79 full tables, excluding 080_Books. Tables average 46,911 rows and 22.8 columns. Measures tabular answer correctness using reference answers and type-specific matching. Details.

  2. BIRD New Dev. 1,534 questions across 11 databases, version dev_20251106. Databases average 6.8 tables; tables average 52,436 rows and 10.6 columns. Measures Text-to-SQL correctness by comparing query results with reference SQL results. Details.

  3. Spider2-Lite SQLite subset. 135 complex SQL questions across 30 databases. Databases average 13.7 tables; tables average 43,009 rows and 7.0 columns. Scored by the official execution-result scorer; missing answers count as incorrect. Covers the SQLite subset only. Details.

Scale averages are calculated over unique base tables, excluding views and internal tables. Datasets use different scoring protocols, so their scores are not directly comparable. These evaluations measure answer correctness, not visualization quality.
