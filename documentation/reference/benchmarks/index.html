Benchmarks

Evaluation results on DataBench, BIRD, and Spider2-Lite, with instructions to run your own tests.

AVA is evaluated on tabular question answering and text-to-SQL tasks. The results below are recorded in the repository's benchmark results. They measure answer or query-result correctness; they do not measure visualization quality.

DataBench

The recorded evaluation uses 1,789 questions on full tables, excluding 080_Books, with GLM-5.1.

Workflow · PythonDirect + Profile85.41%

WorkflowSubset + Profile86.70%
WorkflowLoop84.07%

Profile means dataset statistics are supplied as context. Subset selects relevant profile statistics before analysis. The agent workflow lets the model choose its tools and steps using the AVA Skill.

Run an evaluation

From the repository root, install dependencies and build AVA. Workflow evaluations require Node.js 22.18 or newer and curl for downloading DataBench.

Configure the model in evals/ava-workflow/.env:

Start with a 20-question run on the full-table DataBench dataset:

This small run checks your setup; it does not reproduce the full benchmark score. Keep the model, dataset version, question range, engine, and strategy consistent when comparing runs. Use a new output path when changing conditions: existing answers can be reused when resuming a workflow run.

The evaluation guide covers full runs, offline scoring, and saved reports. Agent evaluations additionally require Node.js 24 or newer and Docker. These commands call your configured model and incur its usage costs.
