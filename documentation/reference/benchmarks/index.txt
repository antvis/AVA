## Dataset notes

<div className="docs-benchmark-notes">

1. <strong id="dataset-databench">DataBench.</strong> <span style={{ color: 'var(--docs-link)', fontWeight: 600 }}>1,789 questions across 79 full tables</span>, excluding `080_Books`. Tables average <span style={{ color: 'var(--docs-link)', fontWeight: 600 }}>46,911 rows and 22.8 columns</span>. Measures tabular answer correctness using reference answers and type-specific matching. [Details](https://github.com/antvis/AVA/blob/ai/evals/databench/README.md).

2. <strong id="dataset-bird">BIRD New Dev.</strong> <span style={{ color: 'var(--docs-link)', fontWeight: 600 }}>1,534 questions across 11 databases</span>, version `dev_20251106`. Databases average <span style={{ color: 'var(--docs-link)', fontWeight: 600 }}>6.8 tables</span>; tables average <span style={{ color: 'var(--docs-link)', fontWeight: 600 }}>52,436 rows and 10.6 columns</span>. Measures Text-to-SQL correctness by comparing query results with reference SQL results. [Details](https://github.com/antvis/AVA/blob/ai/evals/BIRD/README.md).

3. <strong id="dataset-spider2lite">Spider2-Lite SQLite subset.</strong> <span style={{ color: 'var(--docs-link)', fontWeight: 600 }}>135 complex SQL questions across 30 databases</span>. Databases average <span style={{ color: 'var(--docs-link)', fontWeight: 600 }}>13.7 tables</span>; tables average <span style={{ color: 'var(--docs-link)', fontWeight: 600 }}>43,009 rows and 7.0 columns</span>. Scored by the official execution-result scorer; missing answers count as incorrect. Covers the SQLite subset only. [Details](https://github.com/antvis/AVA/blob/ai/evals/spider2lite/README.md).

Scale averages are calculated over unique base tables, excluding views and internal tables. Datasets use different scoring protocols, so their scores are not directly comparable. These evaluations measure answer correctness, not visualization quality.
