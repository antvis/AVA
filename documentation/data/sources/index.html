Working with data

Data sources

Load inline data, local or remote files, and database tables.

CSVInline & fileJSONInline & fileParquetColumnar fileExcelWorkbook sheetsTextLLM extractionSQLiteLocal databaseMySQLDatabasePostgreSQLDatabaseMongoDBDocument databaseSupabaseCloud databaseClickHouseAnalytics databaseCustom extensionExtend AVA in source

Choose a data source above, then use its example and parameter table below. CSV and JSON each support inline content and files.

Connect a source

Create an AVA instance, then call source({ type, options }):

ParameterTypeRequiredMeaning
typeSourceTypeYescsv, csv-file, json, json-file, parquet, excel, text, sqlite, mysql, postgresql, mongodb, supabase, or clickhouse.
optionsSource-specific objectYesUse the matching table below. Field names are relative to options.

source() returns no value. Calling it again replaces the current source and clears its cached schema and profile. Use schema() to inspect the actual table and field names, and call await ava.dispose() when finished.

The examples use Node.js. Supabase and ClickHouse include their required constructor settings alongside the source call. For frontend applications, see browser usage.

CSV reader options

AVA forwards supplied values to read_csv; omitted values use DuckDB reader defaults or detection. Defaults below describe individual reader settings; automatic detection can determine the effective header, delimiter, and types.

typesstring[] | Record<string, string>NoColumn types, by position (list) or by name (struct)
all_varcharbooleanNoSkip type detection and read all columns as VARCHAR. Default false
normalize_namesbooleanNoRemove non-alphanumeric chars from column names; prefix reserved keywords with _
force_not_nullstring[]NoColumns that must not be matched against the NULL string
delimstringNoField delimiter (up to 4 bytes). Default ','
quotestringNoQuote character. Default '"'

commentstringNoCharacter used to initiate comments
new_linestringNoNew line character(s): '\r' | '\n' | '\r\n'
auto_detectbooleanNoAuto detect CSV parameters. Default true
auto_type_candidatesstring[]NoTypes the sniffer considers when detecting column types, e.g. ['BIGINT', 'DATE']
dateformatstringNoDate format used when parsing dates
timestampformatstringNoTimestamp format used when parsing timestamps

ClickHouse

Provide a server endpoint and database. Use url or host; url takes precedence when both are present.

AVA requires an endpoint even though the underlying client has a localhost default.

Forwarded client fields

ClickHouseSourceOptions also accepts the following fields from @clickhouse/client. This table follows the installed client type declarations (1.23.1); these fields are owned by that dependency. AVA forwards them when creating the client.

FieldTypeDefault / meaning
pathnamestringEmpty; extra proxy path.
request_timeoutnumber30000 milliseconds.
max_open_connectionsnumber10 sockets per host.
compressionObjectRequest and response compression; nested fields below.
access_tokenstringUnset; ClickHouse Cloud JWT. Do not combine with username/password.
applicationstringEmpty; application name.
clickhouse_settingsClickHouseSettingsEmpty; server settings map. AVA enforces readonly: '1' on every query, overriding a conflicting setting.
logObjectClient logging options below.
session_idstringEmpty; no explicit server session.
rolestring | string[]Unset; server roles.
http_headersRecord<string, string>Empty; additional request headers.
additional_headersRecord<string, string>Deprecated client alias; use http_headers.
keep_aliveObjectSocket reuse options below.
jsonPartial<JSONHandling>Native JSON.parse / JSON.stringify; callbacks below.
tracerClickHouseTracerUnset; client tracing implementation.
use_multipart_paramsbooleanfalse; always send query parameters as multipart data.
use_multipart_params_autobooleanfalse; use multipart when encoded parameters exceed 4096 characters.
tlsTLS options objectUnset; certificate fields below.
http_agenthttp.Agent | https.AgentUnset; a custom agent supersedes max_open_connections, tls, and keep_alive. Experimental client API.
set_basic_auth_headerbooleantrue; send a Basic Authorization header. Experimental.
capture_enhanced_stack_tracebooleanfalse; capture extended client stacks. Experimental.
max_response_headers_sizenumberUnset; Node.js response header byte limit applies.
connectionConnection<Stream.Readable>Unset; experimental client backend connection. Overrides the default HTTP transport and its options.

All forwarded fields are optional. Server settings are an extensible, server-version-dependent map rather than an AVA-defined finite list. The dependency's ClickHouseSettings type and your server determine accepted keys. Tracer, agent, logger, and connection objects implement the corresponding client contracts; they are not plain AVA configuration objects.
