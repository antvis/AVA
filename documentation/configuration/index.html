Advanced usage

Model configuration

Connect an OpenAI-compatible provider, AI Gateway, or an AI SDK model.

Constructor

llm is required. Omitting engine selects DuckDB; frontend applications must explicitly select javascript.

Model options

FieldTypeRequiredMeaning / default
provider'openai' | 'gateway'NoDefaults to OpenAI-compatible Chat Completions. Gateway reads AI_GATEWAY_API_KEY.
modelstring | LanguageModelYesModel name or a preconfigured AI SDK model instance.
apiKeystringNoAPI key for the LLM provider
baseURLstringNoOptional API base URL
maxRetriesnumberNoMaximum retries for retryable model API failures. Default 3.
onQueryUsage(usage: LanguageModelUsage) => voidNoOptional callback for SQL-generation token usage

String model names use OpenAI-compatible Chat Completions by default. A supplied model object is used directly. Usage callbacks are not a complete accounting stream for every LLM request.

AI Gateway

The gateway provider can also read AI_GATEWAY_API_KEY from the environment when an explicit key is omitted.

Separate retry controls

llm.maxRetries controls model API retries. The direct analysis strategy has a separate maxRetries option for correcting failed executable queries. See analysis strategies.

Credentials in frontend apps

Keep shared provider secrets on the server. For browser-only experiments, obtain credentials at runtime rather than including them in source code or the frontend bundle.
