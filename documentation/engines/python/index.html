Execution engines

Python

Use pandas through local Python or an executor supplied by your application.

Configure

Local execution requires python3 and pandas. Additional file readers may need optional pandas dependencies for Excel or Parquet.

i

Local Python execution is not sandboxed. Use the execute callback with your own isolated environment when that boundary is required.

Engine options

Set engine.type to python. These are all additional fields accepted on engine.

FieldTypeRequiredMeaning / default
execute(code: string) => Promise<ExecutionResult>NoOverride local python3 execution with a custom environment. Local execution is not sandboxed. Run the complete Python script and return its JSON output as ExecutionResult. Source loading and result limits are included in the script; configure remote execution deadlines separately.
queryTimeoutMsnumberNoClient wait limit and local process execution deadline. Default 30000 ms.

Supported sources

Inline CSV and JSON, plus CSV, JSON, Excel, and Parquet files are supported. Files can be local or HTTP(S) URLs. This engine does not accept text extraction or database sources.

Query bindings

pd provides pandas. DataFrames are available in tables, keyed by schema table name. For a single table, df is also provided. Assign the final value to result.

DataFrame and Series indexes are not returned automatically; use reset_index() when those values matter. Each execution starts from fresh input data, so mutations and variables do not persist between calls.

Supply a Python executor

Keep AVA's Python query generation and source handling, and replace where the complete script runs:

YOUR_EXECUTOR is an application-owned service, not an AVA endpoint. It must execute the supplied script with Python and pandas, parse its JSON output, and return an ExecutionResult. Validate that response at the service boundary. A local file path in the script must also exist in the executor environment; alternatively use inline data or accessible URLs.

Callback parameter / resultTypeRequiredMeaning
codestringYesComplete script, including source loading and result limits.
Returned promisePromise<ExecutionResult>YesResolve with schema and data, plus applicable truncation metadata; reject on failure.

See engine options for all engine fields and execution results for the result shape. Enforce deadlines and resource limits in the service itself: aborting the HTTP request only stops the client waiting.
