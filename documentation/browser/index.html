Advanced usage

Browser usage

Use the JavaScript engine without bundling Node.js dependencies.

Import the browser build

The browser entry point registers only the JavaScript engine. Select it explicitly: the AVA constructor otherwise defaults to DuckDB.

Supported sources

Inline json, csv, and text are supported. Text extraction calls the configured model. File paths and direct database connections require a Node.js engine.

Natural language analysis

Configure your provider before using analyze(), translate(), suggest(), or chart recommendations. A model name alone does not supply credentials for those operations.

i

Keep shared API keys on the server. If you use a browser workflow with user-provided credentials, obtain them at runtime.

Execution behavior

Generated JavaScript reads data and stat, and assigns its final output to result. The browser executes code in an iframe with sandbox="allow-scripts" and a restrictive content security policy. See JavaScript engine for the execution contract.
