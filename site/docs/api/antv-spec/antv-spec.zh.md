## 什么是 Spec？

在数据可视化领域，**Spec**（Specification 的缩写，意为“规范”）是一个核心概念。它是一个用于 **声明式定义** 图表的对象，通常采用 JSON 格式。

通过 Spec，您可以精确地描述一个图表应该如何渲染，包括但不限于：

*   **图表类型**: 例如，是折线图（`line`）、饼图（`pie`）还是柱状图（`column`）。
*   **数据**: 用来生成图表的原始数据。
*   **视觉通道**: 如何将数据映射到视觉元素，例如将哪个字段映射到 x 轴，哪个字段映射到 y 轴。
*   **样式和主题**: 图表的颜色、字体、边距、背景等视觉样式。
*   **交互行为**: 例如，鼠标悬停时的提示（tooltip）、图例的点击效果等。

您可以将 Spec 视为一份 **图表的蓝图**。您只需要描述“我想要一个什么样的图表”，而不需要关心底层的具体绘制细节。渲染引擎会根据这份蓝图，自动地将图表绘制出来。

这种声明式的定义方式有以下优点：

*   **易于理解和修改**: JSON 格式的 Spec 结构清晰，易于阅读和修改。
*   **平台无关**: 同一份 Spec 可以在不同的平台（例如 Web、移动端）上渲染出一致的图表。
*   **便于存储和传输**: Spec 本质上是文本，可以轻松地通过网络传输或存储在数据库中。

在 AntV 中，所有的图表库都遵循一套统一的 Spec 规范，这使得在不同图表之间切换和组合变得非常容易。
