## The core workflow

Connect a data source, inspect its structure, ask a question, and optionally generate a chart.

<div className="docs-pipeline">
  <span>Source</span>
  <span aria-hidden="true">→</span>
  <span>Analyze</span>
  <span aria-hidden="true">→</span>
  <span>Visualize</span>
</div>

- **Understand your data.** `schema()` describes tables and fields; `profile()` computes statistics without an LLM call.
- **Ask better questions.** `suggest()` recommends questions using the schema and available profile.
- **Analyze in natural language.** `analyze()` translates, executes, and summarizes a question using the selected strategy.
- **Control individual steps.** Use `translate()` and `query()` separately, or `recommend()` and `viz()` for chart generation.

## Choose an execution engine

| Engine     | Query language  | Environment                    |
| ---------- | --------------- | ------------------------------ |
| DuckDB     | SQL             | Node.js; default               |
| JavaScript | JavaScript      | Browser and Node.js            |
| Python     | Python / pandas | Node.js with a Python executor |
| Supabase   | PostgreSQL SQL  | Node.js; remote execution      |
| ClickHouse | ClickHouse SQL  | Node.js; remote execution      |

The [engine guide](/documentation/engines/overview/) explains supported sources and configuration.
