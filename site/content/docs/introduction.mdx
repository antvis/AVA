AVA is an open-source library for adding data analysis and charts to JavaScript and TypeScript applications. Connect a file or database, then ask a question in plain language, such as “How did sales change from January to February?” AVA uses a language model to turn the question into a query, runs it against your data, and returns the results with a written explanation. You can then generate a chart from those results and display it in your application.

## The core workflow

Connect a data source, ask a question, and optionally generate a chart. AVA generates and runs queries against your data, then explains the results.

{

<div className="docs-pipeline">
  <span>Source</span>
  <span aria-hidden="true">→</span>
  <span>Analyze</span>
  <span aria-hidden="true">→</span>
  <span>Visualize</span>
</div>
}

- **Load data.** Choose a data source type and pass its settings to `source()` to load a file, database, or inline rows. AVA discovers table and column names when analysis needs them.
- **Ask a question.** `analyze()` generates and executes a query, then returns result rows and a summary.
- **Create a chart.** `visualize()` turns the question and result rows into chart HTML.

Use `schema()` to inspect tables and columns, `profile()` to compute statistics, and `semantic()` to add business rules. These steps are optional. See [Inspect your data](/documentation/data/schema/).
