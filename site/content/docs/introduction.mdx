## The core workflow

AVA uses a language model to generate queries and explain results. An execution engine runs those queries against your data; DuckDB is the default in Node.js.

Connect a data source, ask a question, and optionally generate a chart.

{

<div className="docs-pipeline">
  <span>Source</span>
  <span aria-hidden="true">→</span>
  <span>Analyze</span>
  <span aria-hidden="true">→</span>
  <span>Visualize</span>
</div>
}

- **Load data.** `source()` connects a file, database, or inline rows. AVA discovers table and column names when analysis needs them.
- **Ask a question.** `analyze()` generates and executes a query, then returns result rows and a summary.
- **Create a chart.** `visualize()` turns the question and result rows into chart HTML.

Use `schema()` to inspect tables and columns, `profile()` to compute statistics, and `semantic()` to add business rules. These steps are optional. See [Inspect your data](/documentation/data/schema/).

## Choose an execution engine

| Engine     | Query language  | Environment                    |
| ---------- | --------------- | ------------------------------ |
| DuckDB     | SQL             | Node.js; default               |
| JavaScript | JavaScript      | Browser and Node.js            |
| Python     | Python / pandas | Node.js with a Python executor |
| Supabase   | PostgreSQL SQL  | Node.js; remote execution      |
| ClickHouse | ClickHouse SQL  | Node.js; remote execution      |

The [engine guide](/documentation/engines/overview/) explains supported sources and configuration.
