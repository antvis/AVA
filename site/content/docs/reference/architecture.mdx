## Public entry points

[`index.ts`](https://github.com/antvis/AVA/blob/ai/src/index.ts) registers all Node.js engines and exports `AVA` plus public types. [`index.browser.ts`](https://github.com/antvis/AVA/blob/ai/src/index.browser.ts) registers only JavaScript. [`ava.ts`](https://github.com/antvis/AVA/blob/ai/src/ava.ts) coordinates source state, model context, events, and engine lifecycle.

## Context and state

An AVA instance holds one source configuration's active engine, schema, and latest profile. A source may contain multiple tables. Loading a new source clears existing context; profiling enriches later model calls.

Analysis strategies share a runtime containing the engine, model configuration, schema/profile context, and event emitter. Query result limits are normalized through shared utilities.

## Documentation organization

Each topic is a separate MDX file under `site/content/docs/`, grouped into `data/`, `analysis/`, `visualization/`, `engines/`, and `reference/`. This mirrors the public capabilities without exposing every internal helper as a separate user-facing page.
