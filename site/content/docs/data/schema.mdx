`Schema` describes tables, fields, and relations. `Profile` adds statistics.

## Read the schema

```typescript
await ava.source({ type: 'json', options: { data: [{ region: 'East', revenue: 120 }] } });
const schema = await ava.schema();
console.log(schema.tables, schema.relations);
```

`source()` loads data; `schema()` discovers structure once and caches it. Analysis and profiling obtain schema as needed. Direct `query()` does not trigger discovery.

## Schema structure

| Property | Contents |
| --- | --- |
| `tables` | Exposed tables or views |
| `tables[].name` | Name to use in queries |
| `tables[].columnCount` | Number of columns |
| `tables[].fields` | Field `name`, native `type`, optional `nullable` |
| `tables[].indexes` | Index name, columns, uniqueness, optional primary-key flag |
| `relations` | Optional foreign-key relationships between table/column pairs |

Availability depends on the source and engine. A query result's `schema` describes output columns and cannot be used as a source `Schema`.

## Profile a dataset

```typescript
const profile = await ava.profile({ metrics: ['row_count', 'null_count', 'mean'] });
console.log(profile.tables[0].metrics, profile.generatedAt);
```

Each `profile()` call computes fresh statistics and replaces the retained profile. It requires engine support, but no LLM. Analysis, translation, and suggestions reuse the retained profile.

## Select metrics

| Selection | Metrics |
| --- | --- |
| Default | `row_count`, `null_count`, `distinct_count`, `top_values`, `min`, `max`, `mean` |
| Additional | `duplicate_count`, `min_length`, `max_length`, `sum`, `stddev`, `median` |

`metrics` replaces the defaults; `[]` creates a profile without observations. Metrics apply to compatible fields across all tables. Use targeted queries when only a few statistics are needed. See [metric options](/documentation/reference/api/#profile), including `top_values` limits.

## Profile format

A profile includes schema plus table and field `metrics`, field `logicalType`, and `generatedAt` (Unix milliseconds). Missing metrics mean not computed, not zero. Preserve the complete JSON when saving it.

## Supply metadata

Optionally pass an existing schema or profile to skip discovery:

```typescript
await ava.source(config, { profile }); // A profile also supplies schema.
```

Use `{ schema }` for structure only. If both are provided, explicit schema takes precedence. Invalid structure is discovered on demand; invalid profile statistics are ignored. Metadata must match the data and reader settings; AVA does not check freshness.

Calling `profile()` recomputes statistics. Replacing or disposing of the source clears metadata.
