AVA reads fields and records from one Tencent Docs SmartSheet subtable. It supports common field types such as text, numbers, dates, and single select.

## Connect Tencent Docs

For personal use, sign in to the Tencent Docs Open Platform with an account that can access the document. Copy `client_id`, `open_id`, and `access_token`. [Open the Tencent Docs Open Platform](https://docs.qq.com/open#/)

## Get the file and subtable IDs

Open the subtable you want to analyze and copy the URL from your browser. For example, `https://docs.qq.com/smartsheet/EXAMPLE_ID?tab=TAB_ID`.

1. **`fileId`** Take `EXAMPLE_ID` from the path after `/smartsheet/`. Send `value=EXAMPLE_ID` and `type=2` to the Tencent Docs ID converter, then use the returned `data.fileID` in AVA. [File ID conversion](https://docs.qq.com/open/document/app/openapi/v2/file/util/converter.html)
2. **`sheetId`** Use `TAB_ID`, the value of `tab` in the URL. If the URL has no `tab` parameter, use the converted `fileId` to look up the subtables. [List subtables](https://docs.qq.com/open/document/app/openapi/v2/smartsheet/sheet/get_sheet.html)

## Load the data

Fill in the five values below. In the Node.js SDK, pass the configuration object to `ava.source(config)`. In the CLI, save the configuration locally as `tencent-source.json` and run `ava source @tencent-source.json`.

```json
{
  "type": "tencent-smartsheet",
  "options": {
    "fileId": "<native-file-id>",
    "sheetId": "<sheet-id>",
    "clientId": "<client-id>",
    "openId": "<open-id>",
    "accessToken": "<access-token>"
  }
}
```

## Configuration options

| Option | Required | Description |
| --- | --- | --- |
| `fileId` | Yes | The file ID returned by the converter. |
| `sheetId` | Yes | The ID of the subtable to analyze. |
| `clientId` | Yes | The `client_id` from the Open Platform. |
| `openId` | Yes | The `open_id` from the Open Platform. |
| `accessToken` | Yes | The `access_token` from the Open Platform. |
| `maxRecords` | No | Maximum records per load. Defaults to 10,000 and accepts 1–100,000. Exceeding the limit fails the load. |
| `timeoutMs` | No | Time limit for the whole load in milliseconds. Defaults to 60,000 and accepts 1–110,000. |
| `pageSize` | No | Fields or records per request. Defaults to 100 and accepts 1–100. |
| `maxRetries` | No | Retries for transient errors. Defaults to 2 and accepts 0–5. |
