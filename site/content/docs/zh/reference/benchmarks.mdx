<h2 id="dataset-notes">先了解数据集和计分方式</h2>

1. <strong id="dataset-databench">DataBench：</strong>1,789 道问题，覆盖 79 张完整表，排除 `080_Books`。平均每表 46,911 行、22.8 列。根据参考答案与不同结果类型的匹配规则衡量答案正确性。[复现说明](https://github.com/antvis/AVA/blob/ai/evals/databench/README.md)。
2. <strong id="dataset-bird">BIRD New Dev：</strong>版本 `dev_20251106`，1,534 道问题，覆盖 11 个数据库。平均每库 6.8 张表，每表 52,436 行、10.6 列。对照参考 SQL 的执行结果评估 Text-to-SQL。[复现说明](https://github.com/antvis/AVA/blob/ai/evals/BIRD/README.md)。
3. <strong id="dataset-spider2lite">Spider2-Lite SQLite 子集：</strong>135 道复杂 SQL 问题，覆盖 30 个数据库。平均每库 13.7 张表，每表 43,009 行、7.0 列。使用官方执行结果评分器，未回答计为错误，结果只代表 SQLite 子集。[复现说明](https://github.com/antvis/AVA/blob/ai/evals/spider2lite/README.md)。

规模均值只统计唯一基础表，不含视图和内部表。不同数据集的评分协议不同，分数不能直接横向比较。这些评测衡量的是答案正确性，不是图表质量。表中的 pp 表示百分点，耗时单位 s 表示秒。
