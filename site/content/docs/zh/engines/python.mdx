<h2 id="configure">启用 Python</h2>

```typescript
const ava = new AVA({
  llm: { model: 'YOUR_MODEL', apiKey: process.env.OPENAI_API_KEY },
  engine: { type: 'python', queryTimeoutMs: 30000 },
});
```

本地环境需要 `python3` 和 pandas；读取 Excel、Parquet 时还可能需要对应的 pandas 可选依赖。

<Callout>本地 Python 执行不在沙箱中。需要隔离时，通过 `execute` 接入自己管理的执行环境。</Callout>

<h2 id="engine-options">引擎参数</h2>

| 字段 | 类型 | 默认行为 |
| --- | --- | --- |
| `execute` | `(code: string) => Promise<ExecutionResult>` | 不提供时在本地用 python3 执行；提供后交给你的执行器运行完整脚本。 |
| `queryTimeoutMs` | `number` | 默认 `30000` 毫秒，控制客户端等待与本地进程执行时限。 |

<h2 id="supported-sources">支持的数据</h2>

支持内存 CSV、JSON，以及本地或 HTTP(S) 地址的 CSV、JSON、Excel、Parquet 文件。不接收文本提取或数据库源。`source()` 保存验证后的配置，实际读取发生在查询或元数据计算时，每次查询都会重新读取输入。

<h2 id="query-bindings">Python 查询约定</h2>

`pd` 是 pandas；`tables` 按表名提供 DataFrame。只有一张表时还会提供 `df`。把最终值赋给 `result`。

```typescript
const result = await ava.query("result = df.groupby('region', as_index=False)['revenue'].sum()");
```

DataFrame 和 Series 的索引不会自动成为返回列，需要时先 `reset_index()`。不同执行之间不保留变量和数据修改。

<h2 id="supply-a-python-executor">接入自己的 Python 执行服务</h2>

```typescript
import { AVA, type ExecutionResult } from '@antv/ava';

const ava = new AVA({
  llm: { model: 'YOUR_MODEL', apiKey: process.env.OPENAI_API_KEY },
  engine: {
    type: 'python',
    queryTimeoutMs: 30000,
    execute: async (code: string): Promise<ExecutionResult> => {
      const response = await fetch('https://YOUR_EXECUTOR/run', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ code }),
        signal: AbortSignal.timeout(30000),
      });
      if (!response.ok) throw new Error(`Python execution failed: ${response.status}`);
      return (await response.json()) as ExecutionResult;
    },
  },
});
```

`YOUR_EXECUTOR` 代表你管理的服务，并非 AVA 的接口。服务需要运行包含数据加载与结果限制的完整脚本，解析 JSON 输出，返回 `ExecutionResult`，失败时拒绝 Promise。

在服务边界验证返回结构，并自行设置执行期限和资源上限。HTTP 请求取消只代表客户端不再等待，不保证远程任务已经停止。脚本中的本地路径也必须在执行环境中存在；否则使用内存数据或可访问的 URL。

返回结构见 [ExecutionResult](/documentation/reference/api/#executionresult)。
