<h2 id="configure">启用 JavaScript</h2>

```typescript
import { AVA } from '@antv/ava/browser';

const ava = new AVA({
  llm: { model: 'YOUR_MODEL' },
  engine: { type: 'javascript' },
});
```

Node.js 可以从 `@antv/ava` 导入；前端使用 `@antv/ava/browser`。两种入口都需要显式选择 JavaScript 引擎。

<h2 id="supported-sources">加载内存数据</h2>

支持内存 CSV、JSON 和文本；文本提取会调用模型。示例：

```typescript
await ava.source({
  type: 'json',
  options: { data: [{ revenue: 120 }, { revenue: 90 }] },
});
const result = await ava.query('const result = [{ revenue: data.reduce((sum, row) => sum + row.revenue, 0) }];');
```

本地文件路径和直接数据库连接不由这个引擎处理。

<h2 id="query-bindings">查询中的变量</h2>

`data` 是已加载的数据，`stat` 提供统计上下文。查询代码把结果赋给 `result`，例如 `const result = data;`。请保留实际字段名，不要为了界面语言重命名用户数据。

<h2 id="execution">运行边界</h2>

浏览器中使用限制性 CSP 和带 `sandbox="allow-scripts"` 的 iframe；Node.js 使用自身的执行环境。两种环境的执行等待上限均为 10 秒；Node.js 使用 `node:vm`。输入在执行前复制，非数组结果会规范为含 `value` 字段的一行，再应用返回结果限制。不要把任意语言的执行边界理解为同一种安全隔离机制。
