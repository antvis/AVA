<Heading as="h2" id="configure">配置</Heading>

```typescript
const ava = new AVA({
  llm: { model: 'YOUR_MODEL', apiKey: process.env.OPENAI_API_KEY },
  engine: {
    type: 'duckdb',
    memoryLimit: '512MB',
    threads: 1,
    queryTimeoutMs: 30000,
    maxTempDirectorySize: '1GB',
  },
});
```

DuckDB 是 Node.js 的默认引擎。它创建内存实例，将数据源注册为表或视图；生成 SQL 时使用 schema 和可选的 profile。

<Heading as="h2" id="engine-options">引擎选项</Heading>

将 `engine.type` 设为 `duckdb`。`engine` 接受的全部额外字段如下。

| 字段 | 类型 | 必填 | 含义与默认值 |
| -------------------------- | --------- | -------- | ------------------------------------------------------------------------------- |
| `memoryLimit` | `string` | 否 | 内存限制，例如 `'512MB'`，默认 `'512MB'`。 |
| `threads` | `number` | 否 | 工作线程数，默认 1。 |
| `maxTempDirectorySize` | `string` | 否 | 临时溢写目录的大小上限，例如 `'1GB'`；不设置则不限制。 |
| `queryTimeoutMs` | `number` | 否 | 单次查询超时，单位毫秒，默认 30000。 |
| `allowCommunityExtensions` | `boolean` | 否 | 数据源加载明确需要社区扩展时，允许启用 DuckDB 社区扩展。 |

<Heading as="h2" id="resource-limits">资源限制</Heading>

默认内存上限为 512 MB，使用一个工作线程，查询超时为 30 秒。`maxTempDirectorySize` 可选，省略时不会设置溢写目录大小上限。

这些选项与限制返回结果的 `maxRows`、`maxResultBytes` 相互独立。

<Heading as="h2" id="source-support">数据源支持</Heading>

支持内存 CSV、JSON、文本，本地或远程 CSV、JSON、Parquet、Excel，以及 MySQL、PostgreSQL、SQLite、MongoDB 数据源。配置方式见[接入数据](/documentation/data/sources/)。

<Heading as="h2" id="execution-security">执行安全策略</Heading>

AVA 为 DuckDB 内置了以下安全策略，降低模型生成 SQL 带来的风险：

- **只读执行**：只允许执行一条只读 `SELECT` 语句，拒绝写入操作和多语句查询。
- **限制外部访问**：数据源注册后关闭外部访问，限制本地文件访问，并锁定连接配置，防止查询修改安全设置。
- **禁用自动安装扩展**：默认禁用扩展的自动安装、自动加载和未签名扩展；社区扩展默认关闭，仅在数据源明确需要时启用。
- **限制资源消耗**：默认限制内存、工作线程和查询时间，也可配置临时溢写空间上限。
- **限制返回结果**：通过 `maxRows` 和 `maxResultBytes` 控制返回结果的行数和大小，避免返回过大的数据集。
