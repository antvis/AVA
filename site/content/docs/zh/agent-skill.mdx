<Heading as="h2" id="what-the-skill-does">Agent 和 AVA 各负责什么</Heading>

**Agent** 理解问题、规划分析、编写查询并解释结果； **AVA** 负责连接数据、执行查询和渲染图表。Skill 则告诉 Agent 怎样把这些工具串成完整的分析流程。

你可以让它比较不同时期、探索数据集、排查变化，或基于已核实的结果生成图表。从本地 CSV、JSON、Parquet、Excel、SQLite 文件开始，也可以使用已配置的[数据库连接](/documentation/data/sources/)。

<Callout>
  Skill 的核心流程沿用 Agent 已有的模型。加载结构化数据、查看结构、
  计算统计信息、执行查询，以及根据图表配置渲染结果，都不需要额外的 AVA 模型密钥。
  Agent 自身的模型调用仍按其服务商的规则计费。
</Callout>

示例查询使用 `data` 表，这是 AVA 的 DuckDB CSV 加载器暴露的表名。分析自己的数据时，应先让 Agent 运行 `ava schema`，再根据实际结构编写查询。如果想自行渲染已保存的图表配置，下载后运行：

<Heading as="h2" id="manual-installation">手动安装</Heading>

CLI 需要 **Node.js 22.13 或更高版本**。分别安装 CLI 和 Skill：

```bash
npm install -g @antv/ava
npx --yes skills add antvis/AVA --skill ava --yes
```

这会全局安装 CLI，并为当前项目中检测到的 Agent 安装 Skill。[Skill 安装器](https://github.com/vercel-labs/skills#options)也支持用 `--agent` 指定 Agent，或用 `--global` 跨项目安装。

检查安装结果；如果 Agent 尚未发现 Skill，开启一个新会话：

```bash
ava --help
ava source --help
npx --yes skills list
```

<Heading as="h2" id="model-configuration">什么时候需要配置模型</Heading>

Agent 可以用自身的推理能力，结合 `source`、`schema`、`query` 和 `viz` 完成这个示例。这条流程不需要单独配置 AVA 的模型。

直接调用模型的 AVA 命令——`analyze`、`suggest`、`translate`、`recommend`、`visualize`——以及文本提取，都需要[模型配置](/documentation/configuration/)。使用数据集会话时，请在运行 `ava source` **之前** 设置相关模型环境变量。

<Heading as="h2" id="troubleshooting">常见问题</Heading>

- **Agent 找不到 Skill。** 在安装 Skill 的项目目录运行 `npx --yes skills list`，确认安装时选中了你的 Agent，再开启新会话。
- **找不到 `ava` 命令。** 检查 npm 全局安装是否成功，以及可执行文件目录是否在 Agent 的 `PATH` 中。
- **数据集不可用。** 会话闲置 30 分钟后会过期。重新加载数据源并使用新的数据集 ID。相关命令需要由同一用户，在相同的运行环境和临时目录中执行。
- **图表为空白。** 检查是否能联网加载图表渲染器，核对图表配置，并用结果表验证数值。

命令选项见 [CLI 参考](/documentation/reference/cli/)；Agent 的完整工作流说明见 [Skill 源码](https://github.com/antvis/AVA/blob/ai/skills/ava/SKILL.md)。
