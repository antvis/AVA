Using AVA through an AI agent? Start with the [Agent Skill guide](/documentation/agent-skill/). This quickstart uses the JavaScript SDK to answer a question and save a chart.

## Install

Use Node.js **22.13 or later**. In your project directory, install AVA 4.x:

```bash
npm install @antv/ava@4
```

## Configure your model

AVA uses a language model to generate queries and explain results. Set your provider credentials in the terminal where you will run the example:

```bash
export OPENAI_API_KEY='<your-api-key>'
export OPENAI_MODEL='gpt-4o-mini'
# For another OpenAI-compatible provider, set its model name above and API URL below:
# export OPENAI_BASE_URL='https://your-provider.example/v1'
```

The example reads these variables explicitly. See [model configuration](/documentation/configuration/) for other providers and AI SDK model objects.

## Run your first analysis

Save this as `analysis.mjs`. It loads three rows with the default DuckDB engine, calculates revenue by region, and saves a chart:

```javascript
import { writeFile } from 'node:fs/promises';
import { AVA } from '@antv/ava';

const ava = new AVA({
  llm: {
    model: process.env.OPENAI_MODEL || 'gpt-4o-mini',
    apiKey: process.env.OPENAI_API_KEY,
    baseURL: process.env.OPENAI_BASE_URL,
  },
});

try {
  await ava.source({
    type: 'json',
    options: {
      data: [
        { region: 'East', revenue: 120 },
        { region: 'West', revenue: 90 },
        { region: 'East', revenue: 80 },
      ],
    },
  });

  const result = await ava.analyze('Show total revenue by region as a column chart');
  console.log(result.text);
  console.table(result.data);

  const chart = await ava.visualize(result);
  if (chart) {
    await writeFile('revenue.html', chart.html);
    console.log('Saved revenue.html');
  }
} finally {
  await ava.dispose();
}
```

Run it from the same directory:

```bash
node analysis.mjs
```

The answer should show **East: 200** and **West: 90**. Summary wording, row order, and column names can vary with the model. Open `revenue.html` in a browser with internet access to view the chart. If no chart is recommended, `visualize()` returns `null`.

## What happens in this example

- `source()` loads the data. Calling it again replaces the current source.
- `analyze()` discovers table and column names, generates and executes a query, and summarizes the result. It returns rows in `data` and a summary in `text`.
- `visualize()` uses the question and result rows to generate chart HTML.
- `dispose()` releases connections and other engine resources, including when a call fails.

You can inspect structure with `schema()`, compute statistics with `profile()`, or add business rules with `semantic()`. These are optional for this example.
