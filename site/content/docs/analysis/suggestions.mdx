## Suggest questions

```typescript
const suggestions = await ava.suggest(5);
for (const item of suggestions) {
  console.log(item.query, item.score, item.reason);
}
```

`suggest(count = 3)` uses the latest profile if available, otherwise the schema. It requires a loaded source and calls the configured model.

## Results

Each suggestion contains `query`, `score`, and `reason`. Scores are clamped to the range 0–1, results are sorted in descending order, and at most `count` entries are returned. The model is prompted to match the dataset's language.

## Follow a suggestion

```typescript
await ava.profile();
const suggestions = await ava.suggest(3);
if (suggestions.length > 0) {
  const result = await ava.analyze(suggestions[0].query);
  console.log(result.text);
}
```

An invalid model response rejects the call. Handle errors as you would for other model-facing operations.
