    Analyze

    Execute queries and explore analytical questions with real data.

    Q:“Which region drives the most revenue?”

    SELECT region, SUM(amount) AS total
FROM sales
WHERE YEAR(date) = 2025
GROUP BY region
ORDER BY total DESC;

    ✓ 4 rows · no hallucination · answer grounded in data

Developer Experience

Bring Analytics to Your Agent.

Integrate AVA through an Agent Skill, CLI, or SDK — on your terms.

Give Your Agent a Data Analytics Skill.

Equip compatible agents with a reusable workflow for exploring, analyzing, and visualizing data — using the agent’s own reasoning, with no separate model key.

View the AVA Skill
bash
# install the skills for your agents
$ npx skills add antvis/AVA

# or add the marketplace in Claude Code
$ /plugin marketplace add antvis/AVA

# then, in a new agent session:
"Use the AVA skill to analyze /absolute/path/sales.csv,
 compare sales by region, and generate a chart."
