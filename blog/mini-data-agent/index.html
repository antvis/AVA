Build a Mini Data Agent with AVA

Start with sales data, then build an agent that investigates changes, verifies its results, and delivers findings with charts.

yvonneyxTutorial2026.11.05

To build a Data Agent, start with a small task: give it some sales data, ask which products account for a drop in sales, and have it produce a short report with charts.

At the core of a Data Agent is an analysis loop driven by execution results: the model proposes a query, reads and checks the results, then decides whether more analysis is needed. To make conclusions verifiable, queries need consistent metric definitions, and charts should use the actual computed results.

AVA is an open-source data analysis framework for JavaScript applications and AI agents, designed to connect enterprise data and support business decisions with trustworthy analysis and visualization. Like PandasAI in the Python ecosystem, it supports analyzing data and generating charts through natural language. This tutorial uses AVA for analysis and charting, with the AI SDK coordinating tool calls, to build a Mini Data Agent that supports multi-step analysis and follow-up questions.
