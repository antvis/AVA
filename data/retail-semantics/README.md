# Semantic 对照测试

同一份 [CSV](sales.csv)，配两份内部报表口径：

| 语义契约 | 核心定义 | 核验后的正确结果 |
| --- | --- | --- |
| [财务口径](semantic-finance.json) | 按履约月，代销只计佣金 | **下降13.87%**，主要来自深圳南山店线上升降桌 |
| [交易口径](semantic-trading.json) | 按支付月，代销计全额，包含已支付预售 | **增长15.77%**，主要来自北京朝阳店线上升降桌 |

## 使用方式

主测试固定财务经营口径和同一份标答：

- A组：`sales.csv` + `question.txt`，不加载语义。
- B组：相同的数据和问题，加载 `semantic-finance.json`。

固定模型、引擎、schema/profile、工具权限和预算，使用新会话，每组至少运行3次。唯一有意改变的输入是是否提供语义。

`semantic-trading.json` 作为附加测试，检查模型能否遵循另一份业务定义。与主测试分开运行、分开报告。

## 文件

- [sales.csv](sales.csv)：18,971条明细，15,510笔订单，合成数据，快照截至2026-10-05。
- [question.txt](question.txt)：可直接在Playground使用的主问题，不要求下钻。
- [semantic-finance.json](semantic-finance.json)、[semantic-trading.json](semantic-trading.json)：两份口径的完整语义定义。
- [README.md](README.md)：使用说明和两份口径的参考标答，仅供评测者查看。

## 主问题

> 2026年9月的净销售额相比8月发生了什么变化，主要来自哪里？

## 主要标答

财务口径：8月4,293,025.42元，9月3,697,575.18元，减少595,450.24元（下降13.87%）。主要下降组合为深圳南山店/线上商城/电动升降桌，减少558,776.37元，按履约日的订单拐点为9月16日。广州天河店增长66,713.31元，抵消部分下降。

交易口径：8月6,740,687.05元，9月7,803,998.06元，增加1,063,311.01元（增长15.77%）。主要增长组合为北京朝阳店/线上商城/电动升降桌，增加2,764,143.90元；杭州武林店/线上商城/人体工学椅Pro减少1,026,997.73元，抵消部分增长。

## 评测约定

- 模型只能获得数据、当次问题和指定的语义。不要提供 `README.md`，其中包含答案。
- 比较金额、方向、主要来源、时间归属和订单粒度，保留增长抵消项；不按回答长度或下钻步骤数评分。
- 核对具体金额、门店、渠道、SKU和日期；以万元等单位展示时，容忍相应的舍入误差。
- 无语义时合理询问口径，应单独记录，不当作幻觉。
- 数据包含佣金与流水、跨月归属、非销售订单、一单多行和销售/履约门店差异；这些规则会真实影响答案。语义中不包含异常地点或结论。

## 校验

以上标答已通过独立逐行金额汇总和参考SQL交叉核验。尚未运行模型对照，不能据此宣称准确率提升。订单数据也无法独立确认缺货、投放等业务原因。
