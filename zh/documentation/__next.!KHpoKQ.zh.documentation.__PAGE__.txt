从一个问题开始，了解 AVA 如何连接数据、执行分析并呈现结果。

<Heading as="h2" id="the-core-workflow">核心工作流</Heading>

先接入数据，看看有哪些表和字段，再提出问题。拿到结果后，可以继续把它画成图表。

{

<div className="docs-pipeline">
  <span>接入数据</span>
  <span aria-hidden="true">→</span>
  <span>分析数据</span>
  <span aria-hidden="true">→</span>
  <span>生成图表</span>
</div>
}

- **先看清数据有什么。** `schema()` 自动发现表和字段；需要统计信息时调用 `profile()`，有业务口径要交代时使用 `semantic()`。参见[了解数据结构](/documentation/data/schema/)。
- **不知道从哪里问起？** `suggest()` 会结合数据结构和已有统计信息，推荐值得分析的问题。
- **直接描述你要分析什么。** `analyze()` 按所选策略生成查询、执行并整理结论。
- **也可以只用其中一步。** 想先看代码再执行，就分开调用 `translate()` 和 `query()`；已有结果要画图，可以分别使用 `recommend()` 和 `viz()`。

完整的方法签名、参数和返回结构见 [API 参考](/documentation/reference/api/)。

<Heading as="h2" id="choose-an-execution-engine">选择执行引擎</Heading>

| 引擎 | 查询语言 | 运行环境 |
| ---------- | --------------- | ------------------------------ |
| DuckDB | SQL | Node.js，默认引擎 |
| JavaScript | JavaScript | 浏览器和 Node.js |
| Python | Python / pandas | Node.js，需提供 Python 执行器 |
| Supabase | PostgreSQL SQL | Node.js，远程执行 |
| ClickHouse | ClickHouse SQL | Node.js，远程执行 |
| Snowflake | Snowflake SQL | Node.js，远程执行 |

各引擎支持的数据源和配置方式见[执行引擎](/documentation/engines/overview/)。
