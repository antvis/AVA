理解与接入数据

接入数据

连接内存数据、文件、数据库和飞书多维表格。

CSV内存数据与文件JSON内存数据与文件Parquet列式文件Excel工作簿与工作表文本模型提取SQLite本地数据库MySQL数据库PostgreSQL数据库MongoDB文档数据库Supabase云数据库ClickHouse分析型数据库Snowflake云数据仓库自定义扩展注册自己的引擎

在上方找到你的数据类型，再参照对应示例，填入自己的路径或连接信息。CSV 和 JSON 既可以读文件，也可以直接传入内容。

接入数据源

创建 AVA 实例，然后调用 source(config)，传入数据位置与读取设置：

参数类型必填含义
typeSourceType是支持 csv、csv-file、json、json-file、parquet、excel、text、sqlite、mysql、postgresql、mongodb、supabase、clickhouse、snowflake、feishu-bitable。
options数据源对应的对象是使用下方对应的数据源参数表，字段名均相对于 options。

source() 没有返回值，负责为执行准备数据。结构发现会推迟到 schema() 或其他操作需要时进行。再次调用 source() 会替换当前数据源并清空元数据缓存。使用 schema() 查看表名与字段名，结束后调用 await ava.dispose()。

示例均在 Node.js 中运行。Supabase、ClickHouse 和 Snowflake 的示例同时给出了必需的构造函数配置。前端应用请参考浏览器用法。

CSV

直接传入 CSV

设置 type: 'csv'，以字符串传入 CSV 内容。

字段类型必填含义与默认值
csvstring是原始 CSV 字符串。
optionsCSVReadOptions否CSV 读取选项。

读取 CSV 文件

设置 type: 'csv-file'，传入本地路径或 HTTP(S) URL。URL 需要鉴权时，可在 options.headers 中提供请求头。

远程 CSV、JSON、Parquet 和 Excel 文件只要传入非空 headers，就仅允许同来源跳转（协议、主机名和有效端口均相同），最多跳转 20 次。此规则同时适用于 DuckDB 和 Python，包括自定义 Python 执行器。跨来源跳转会在发送下一次请求前报错，即使请求头只有 Accept，或跳转是从 HTTP 升级到 HTTPS。未传请求头或传入 headers: {} 时，保留底层下载器原有的跳转行为。需要从其他来源下载受保护文件时，请直接使用已确认可信的最终地址。

字段类型必填含义与默认值
pathstring是本地文件路径或 HTTP(S) URL。
headersRecord<string, string>否远程数据源的 HTTP 请求头，例如 Authorization。
optionsCSVReadOptions否CSV 读取选项。

飞书多维表格

在 Node.js 的 DuckDB 引擎中使用 type: 'feishu-bitable'。记录会暴露为名为 data 的只读视图。

首次接入请按飞书多维表格配置指南完成应用创建、权限授权和凭证绑定，指南包含流程示意图、CLI / SDK 示例与常见问题。

提供 url，或同时提供 appToken 与 tableId，并设置 appId、appSecret。CLI 也会从 AVA_FEISHU_APP_ID、AVA_FEISHU_APP_SECRET 或 ~/.ava/feishu.json 读取凭证。

支持 /base/ 链接和知识库中的 /wiki/ 链接。Wiki 链接要求应用具备知识库读取权限并加入相应知识空间，才能解析多维表格。URL 中的 view 参数会被忽略。人员、附件、链接、位置、群组等复杂单元格会转换为文本，多个值通常以逗号分隔；公式和查找引用字段按返回值类型转换。

Snowflake

在 Node.js 中使用 snowflake 数据源和引擎，分析 Snowflake 仓库中的表和视图。每个数据源对应一个 schema，查询结果返回 AVA。

权限

准备好仓库、数据库和 schema。连接角色需要三者的 USAGE 权限，以及待分析表和视图的 SELECT 权限。SNOWFLAKE_SAMPLE_DATA 这类共享数据库需要授予 IMPORTED PRIVILEGES。请勿向该角色授予存储过程、外部函数或集成的使用权限。

连接字段

将引擎和数据源类型均设为 snowflake，填入账号、凭证和仓库信息：

字段类型必填含义与默认值
accountstring是账号标识，格式为 orgname-accountname。
databasestring是要发现和查询的数据库。
schemastring否暴露其中表和视图的 schema，也是会话的默认 schema。默认 PUBLIC。
warehousestring否执行查询的仓库，默认使用用户的 DEFAULT_WAREHOUSE。
rolestring否会话使用的角色，默认使用用户的 DEFAULT_ROLE。请使用只读角色。
usernamestring多数认证方式必填登录名。
authenticatorstring否驱动的认证方式，如 SNOWFLAKE_JWT、PROGRAMMATIC_ACCESS_TOKEN 或 OAUTH。默认 SNOWFLAKE（密码）。
privateKeystringSNOWFLAKE_JWT 时必填PEM 格式私钥；也可用 privateKeyPath 从文件读取，加密的私钥用 privateKeyPass 提供口令。
tokenstring令牌类认证时必填Programmatic access token 或 OAuth 访问令牌；也可用 tokenFilePath 从文件读取。
passwordstringSNOWFLAKE 时必填密码。Snowflake 正在逐步停用单因素密码登录，建议使用密钥对或令牌。
queryTimeoutMsnumber否单条语句的时限（毫秒）。由 Snowflake 执行（语句超时和排队超时），到期时客户端也会取消语句。默认 30000。

其他驱动连接选项，如 host、代理设置和 queryTag（默认 AVA），会透传给驱动。结果格式和会话清理由 AVA 管理。数据库、schema 或仓库不存在或未授权时，加载会报错。

查询执行

用 schema() 查看已授权的表、视图和声明的键，用 query() 执行 Snowflake SQL，或用 analyze() 以自然语言提问。analyze() 会将问题和数据集元数据发送给配置的模型来生成 SQL；默认还会将查询结果发送给模型生成摘要，传入 { includeSummary: false } 可跳过摘要。

  • 使用单条只读 SELECT（支持 WITH），按 schema() 列出的名称为表和列加双引号。存储过程、SYSTEM$ 函数，以及 IDENTIFIER(name)(...) 形式的动态函数调用会被拒绝。
  • maxRows 和 maxResultBytes 分别限制返回结果的行数和大小。
  • NUMBER 在转换不损失数字位数时转为 JavaScript 数字，更大或更精确的值保留为十进制字符串；浮点数的 NaN 和无穷大保留为字符串。日期使用 YYYY-MM-DD，时间和时间戳带九位小数，时区类型附带偏移量。VARIANT、OBJECT 和 ARRAY 是解析后的 JSON，BINARY 是十六进制文本。
