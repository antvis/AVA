<Heading as="h2" id="connect-a-source">接入数据源</Heading>

调用 `ava.source()` 时，可以传入一份数据源配置，也可以传入非空的配置数组。每份配置描述数据来自哪里以及如何读取。

| 字段 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `type` | `string` | 是 | 数据源类型，支持的取值见上方对应的数据源文档。 |
| `options` | 数据源对应的对象 | 是 | 对应数据源的读取或连接设置。 |
| `name` | `string` | 否 | 接入多个数据源时，用作表名的前缀。 |

每次调用都会先释放当前数据集并清空元数据，再加载新数据。加载失败后，实例没有活动数据集。加载成功后，用 `ava.schema()` 查看表结构，使用完毕后调用 `await ava.dispose()` 释放资源。

<Heading as="h3" id="connect-one-source">接入单个数据源</Heading>

传入一个配置对象。以下代码使用 Node.js SDK 的默认引擎。

```typescript
import { AVA } from '@antv/ava';

const ava = new AVA({
  llm: { model: 'YOUR_MODEL', apiKey: process.env.OPENAI_API_KEY },
});

await ava.source({
  type: 'json',
  options: { data: [{ city: 'Hangzhou', revenue: 120 }] },
});
```

<Heading as="h3" id="connect-multiple-sources">接入多个数据源</Heading>

在 Node.js SDK 中，使用默认的 DuckDB 引擎，并向 `ava.source()` 传入数据源配置数组。

- 为每个数据源设置唯一的 **`name`**。
- 接入两个或更多数据源时，`ava.schema()` 按 **`源名.表名`** 列出表。CSV 提供一张名为 `data` 的表，Excel 工作簿中的每张选定工作表各对应一张表。
- **只接入一个数据源**时，配置对象和单元素数组都沿用原表名。

<Callout>
  在 CLI 中运行 `ava source A B C`，可将多个数据源加载到同一会话。详见[命令行的数据源输入](/documentation/reference/cli/#source-inputs-and-engines)。
</Callout>

```typescript
await ava.source([
  { name: 'orders', type: 'csv-file', options: { path: './sales.csv' } },
  { name: 'workbook', type: 'excel', options: { path: './sales.xlsx' } },
]);

const schema = await ava.schema();
```
