<Heading as="h2" id="connect-a-source">接入数据源</Heading>

创建 AVA 实例，然后调用 `source(config)`，传入数据位置与读取设置：

```typescript
import { AVA } from '@antv/ava';

const ava = new AVA({
  llm: { model: 'YOUR_MODEL', apiKey: process.env.OPENAI_API_KEY },
});

await ava.source({
  type: 'json',
  options: {
    data: [
      { city: 'Hangzhou', revenue: 120 },
      { city: 'Shanghai', revenue: 200 },
      { city: 'Beijing', revenue: 160 },
    ],
  },
});

const schema = await ava.schema();
```

| 参数 | 类型 | 必填 | 含义 |
| --------- | ---------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `type` | `SourceType` | 是 | 支持 `csv`、`csv-file`、`json`、`json-file`、`parquet`、`excel`、`text`、`sqlite`、`mysql`、`postgresql`、`mongodb`、`supabase`、`clickhouse`、`feishu-bitable`。 |
| `options` | 数据源对应的对象 | 是 | 使用下方对应的数据源参数表，字段名均相对于 `options`。 |

`source()` 没有返回值，负责为执行准备数据。结构发现会推迟到 `schema()` 或其他操作需要时进行。再次调用 `source()` 会替换当前数据源并清空元数据缓存。使用 `schema()` 查看表名与字段名，结束后调用 `await ava.dispose()`。

示例均在 Node.js 中运行。Supabase 和 ClickHouse 的示例同时给出了必需的构造函数配置。前端应用请参考[浏览器用法](/documentation/browser/)。

<Heading as="h2" id="csv">CSV</Heading>

<Heading as="h3" id="inline-csv">直接传入 CSV</Heading>

设置 `type: 'csv'`，以字符串传入 CSV 内容。

```typescript
await ava.source({
  type: 'csv',
  options: { csv: 'city,revenue\nHangzhou,120\nShanghai,200\nBeijing,160' },
});
```

| 字段 | 类型 | 必填 | 含义与默认值 |
| --------- | ---------------- | -------- | ------------------------------------------ |
| `csv` | `string` | 是 | 原始 CSV 字符串。 |
| `options` | `CSVReadOptions` | 否 | [CSV 读取选项](#csv-reader-options)。 |

<Heading as="h3" id="csv-files">读取 CSV 文件</Heading>

设置 `type: 'csv-file'`，传入本地路径或 HTTP(S) URL。URL 需要鉴权时，可在 `options.headers` 中提供请求头。

远程 CSV、JSON、Parquet 和 Excel 文件只要传入非空 `headers`，就仅允许同来源跳转（协议、主机名和有效端口均相同），最多跳转 20 次。此规则同时适用于 DuckDB 和 Python，包括自定义 Python 执行器。跨来源跳转会在发送下一次请求前报错，即使请求头只有 `Accept`，或跳转是从 HTTP 升级到 HTTPS。未传请求头或传入 `headers: {}` 时，保留底层下载器原有的跳转行为。需要从其他来源下载受保护文件时，请直接使用已确认可信的最终地址。

```typescript
await ava.source({
  type: 'csv-file',
  options: {
    path: 'https://example.com/sales.csv',
    headers: { Authorization: 'Bearer YOUR_TOKEN' },
    options: { header: true, delim: ';' },
  },
});
```

| 字段 | 类型 | 必填 | 含义与默认值 |
| --------- | ------------------------ | -------- | ---------------------------------------------------- |
| `path` | `string` | 是 | 本地文件路径或 HTTP(S) URL。 |
| `headers` | `Record<string, string>` | 否 | 远程数据源的 HTTP 请求头，例如 Authorization。 |
| `options` | `CSVReadOptions` | 否 | [CSV 读取选项](#csv-reader-options)。 |

<Heading as="h3" id="csv-reader-options">CSV 读取选项</Heading>

DuckDB 引擎的 `csv`、`csv-file` 数据源可在 `options.options` 中使用以下字段，全部可选。AVA 将显式提供的值转发给 `read_csv`；省略时使用 DuckDB 的默认值或自动检测结果。下表说明各读取选项自身的默认值，实际表头、分隔符和类型也可能由自动检测确定。

| 字段 | 类型 | 必填 | 含义与默认值 |
| ---------------------- | ------------------------------------ | -------- | ----------------------------------------------------------------------------------------------- |
| `header` | `boolean` | 否 | 文件首行是否包含列名，默认 false。 |
| `names` | `string[]` | 否 | 列名列表。 |
| `columns` | `Record<string, string>` | 否 | 列名到类型的映射，例如 &#123; col1: 'INTEGER' &#125;；设置后关闭结构自动检测。 |
| `types` | `string[] \| Record<string, string>` | 否 | 按位置提供类型列表，或按列名提供类型映射。 |
| `all_varchar` | `boolean` | 否 | 跳过类型检测，将所有列读为 VARCHAR，默认 false。 |
| `normalize_names` | `boolean` | 否 | 移除列名中的非字母数字字符，并为保留字添加下划线前缀。 |
| `force_not_null` | `string[]` | 否 | 不参与 NULL 字符串匹配的列。 |
| `delim` | `string` | 否 | 字段分隔符，最多 4 字节，默认 `','`。 |
| `quote` | `string` | 否 | 引号字符，默认 `'"'`。 |
| `escape` | `string` | 否 | 引号包裹的字段内，用于转义引号的字符，默认 `'"'`。 |
| `comment` | `string` | 否 | 注释起始字符。 |
| `new_line` | `string` | 否 | 换行符：`'\r'`、`'\n'` 或 `'\r\n'`。 |
| `auto_detect` | `boolean` | 否 | 自动检测 CSV 参数，默认 true。 |
| `auto_type_candidates` | `string[]` | 否 | 检测列类型时考虑的候选类型，例如 `['BIGINT', 'DATE']`。 |
| `dateformat` | `string` | 否 | 解析日期使用的格式。 |
| `timestampformat` | `string` | 否 | 解析时间戳使用的格式。 |
| `decimal_separator` | `string` | 否 | 数字的小数分隔符，默认 `'.'`。 |
| `thousands` | `string` | 否 | 千位分隔符，须为单个字符，且与 decimal_separator 不同。 |
| `nullstr` | `string \| string[]` | 否 | 代表 NULL 的一个或多个字符串。 |
| `allow_quoted_nulls` | `boolean` | 否 | 允许将引号包裹的值转换成 NULL，默认 true。 |
| `sample_size` | `number` | 否 | 自动检测时采样的行数，默认 20480。 |
| `buffer_size` | `number` | 否 | 读取缓冲区大小，单位字节，默认 `16 * max_line_size`。 |
| `files_to_sniff` | `number` | 否 | 多文件结构检测时采样的文件数；-1 表示全部，默认 10。 |
| `max_line_size` | `number` | 否 | 单行大小上限，单位字节，默认 2000000。 |
| `parallel` | `boolean` | 否 | 使用并行 CSV 读取器，默认 true。 |
| `skip` | `number` | 否 | 跳过每个文件开头的行数，默认 0。 |
| `ignore_errors` | `boolean` | 否 | 忽略解析错误，默认 false。 |
| `null_padding` | `boolean` | 否 | 对较短的行在右侧补 NULL，默认 false。 |
| `strict_mode` | `boolean` | 否 | 遇到任何问题即抛错，默认 true。 |
| `store_rejects` | `boolean` | 否 | 跳过出错行并保存到拒绝记录表，默认 false。 |
| `rejects_table` | `string` | 否 | 保存出错行的临时表名，默认 `'reject_errors'`。 |
| `rejects_scan` | `string` | 否 | 保存出错扫描的临时表名，默认 `'reject_scans'`。 |
| `rejects_limit` | `number` | 否 | 每个文件记录的出错行数上限；0 表示不限制，默认 0。 |
| `encoding` | `string` | 否 | 文件编码，可选 `'utf-8'`、`'utf-16'`、`'latin-1'`，默认 `'utf-8'`。 |
| `compression` | `string` | 否 | 压缩方式，可选 `'none'`、`'gzip'`、`'zstd'`，默认根据扩展名检测。 |
| `union_by_name` | `boolean` | 否 | 多个文件按列名而非列位置对齐，默认 false。 |
| `hive_partitioning` | `boolean` | 否 | 将路径解释为 Hive 分区路径，默认自动检测。 |
| `filename` | `boolean` | 否 | 为每行添加保存来源文件路径的 `filename` 列，默认 false。 |

<Heading as="h3" id="json-files">读取 JSON 文件</Heading>

```typescript
await ava.source({
```

<Heading as="h3" id="json-reader-options">JSON 读取选项</Heading>

使用 DuckDB 时，两种 JSON 数据源均接受 `options.options`，所有字段可选。
`JSONReadOptions` 暴露完整的 [DuckDB JSON 读取参数](https://duckdb.org/docs/current/data/json/loading_json)：

| 参数 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `auto_detect` | `boolean` | `true` | 推断数据结构。 |
| `columns` | `Record<string, string>` | 未设置 | 列名到 DuckDB 类型的映射，同时用于选择列。 |
| `compression` | `'auto_detect' \| 'none' \| 'gzip' \| 'zstd'` | `'auto_detect'` | 压缩编解码方式。 |
| `dateformat` | `string` | `'iso'` | 日期格式。 |
| `field_appearance_threshold` | `number` | `0.1` | 稀疏对象推断为 MAP 的阈值。 |
| `filename` | `boolean` | `false` | 在 `SELECT *` 中包含文件名。 |
| `format` | `'auto' \| 'unstructured' \| 'newline_delimited' \| 'array'` | `'auto'` | `read_json` 的输入组织形式。 |
| `hive_partitioning` | `boolean` | 自动检测 | 根据路径识别分区。 |
| `ignore_errors` | `boolean` | `false` | 跳过错误，仅适用于 NDJSON。 |
| `map_inference_threshold` | `number` | `200` | STRUCT 子字段数量阈值；-1 关闭 MAP 推断。 |
| `maximum_depth` | `number` | `-1` | 结构推断深度；-1 表示不限。 |
| `maximum_object_size` | `number` | `16777216` | 单个对象的字节上限。 |
| `maximum_sample_files` | `number` | `32` | 采样文件数量。 |
| `records` | `'auto' \| 'true' \| 'false'` | `'auto'` | 是否展开对象。 |
| `sample_size` | `number` | `20480` | 采样对象数量；-1 扫描全部。 |
| `timestampformat` | `string` | `'iso'` | 时间戳格式。 |
| `union_by_name` | `boolean` | `false` | 合并数据结构。 |

内存数据会序列化为未压缩的 JSON 数组，请选择与此兼容的读取选项。
远程文件会下载到临时路径，读取压缩 URL 时应显式设置 `compression`。

<Heading as="h2" id="excel">Excel</Heading>

从本地路径或 HTTP(S) URL 读取 `.xlsx` 工作簿。每个被选中的工作表会成为一张独立的表，以工作表名称命名。调用 `schema()` 可查看生成的表与列。

```typescript
await ava.source({
  type: 'excel',
  options: {
    path: './sales.xlsx',
    sheets: [
      { sheet: 'Sales', range: 'A3:F100', header: true },
      { sheet: 'Costs', range: 'B2:C50', header: false },
    ],
  },
});
```

<Heading as="h3" id="source-options">数据源选项</Heading>

| 字段 | 类型 | 必填 | 含义与默认值 |
| --- | --- | --- | --- |
| `path` | `string` | 是 | 本地文件路径或 HTTP(S) URL。 |
| `headers` | `Record<string, string>` | 否 | 远程数据源的 HTTP 请求头，例如 Authorization。 |
| `sheets` | `ExcelSheetOptions[]` | 否 | 要加载的工作表及各自的读取设置；省略时加载全部工作表，并使用 `header: true`。 |

<Heading as="h3" id="sheet-selection-and-reader-options">工作表选择与读取选项</Heading>

`sheets` 中的每一项都包含必填的 `sheet`，以及可选的 `ExcelReadOptions` 字段。读取选项直接放在工作表项上，写法如上例所示。

| 字段 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `sheet` | `string` | 必填 | 精确的工作表名称，同时作为表名。 |
| `range` | `string` | 由引擎推断 | 包含首尾边界的 A1 矩形范围，例如 `B3:F100`。 |
| `header` | `boolean` | `true` | 将所选范围的第一行作为列名；设为 false 时保留为数据。 |
| `all_varchar` | `boolean` | `false` | 仅 DuckDB：将所有单元格读为 VARCHAR。 |
| `ignore_errors` | `boolean` | `false` | 仅 DuckDB：类型转换失败的单元格改为 NULL。 |
| `stop_at_empty` | `boolean` | 有 `range` 时为 `false`，否则为 `true` | 仅 DuckDB：遇到第一个空行时停止读取。 |
| `empty_as_varchar` | `boolean` | `false` | 仅 DuckDB：将空单元格推断为 VARCHAR，而非 DOUBLE。 |

提供 `sheets` 时，列表不能为空；每个工作表名必须存在且只能出现一次。范围必须是有效、有界的 A1 矩形。无效选择及不受支持的字段会被拒绝。

<Heading as="h3" id="engine-behavior">引擎行为</Heading>

两种引擎都支持 `sheet`、`range` 和 `header`。Python 引擎会拒绝上表中的四个 DuckDB 专用选项。

DuckDB 的读取选项遵循 [`read_xlsx`](https://duckdb.org/docs/current/core_extensions/excel#reading-xlsx-files)，但 AVA 默认 `header` 为 true，而非自动推断。例如，要将混合类型单元格保留为文本，并继续读取空行之后的数据：

```typescript
await ava.source({
  type: 'excel',
  options: {
    path: './sales.xlsx',
    sheets: [{ sheet: 'Sales', all_varchar: true, stop_at_empty: false }],
  },
});
```

DuckDB 会拒绝含有字面 XML 实体文本工作表名的工作簿，例如 `Sales &amp; Tax`，因为 Excel 扩展可能将它与另一张表混淆。请重命名这些工作表，或使用 Python 引擎。普通的 &、引号和 Unicode 名称均受支持。

<Heading as="h2" id="mysql">MySQL</Heading>

连接数据库并发现其中的表。

```typescript
await ava.source({
  type: 'mysql',
  options: {
    host: 'localhost',
    database: 'analytics',
    user: 'reader',
    password: process.env.MYSQL_PASSWORD,
  },

```

| 字段 | 类型 | 必填 | 含义与默认值 |
| ---------- | ------------ | -------- | ------------------------------------------- |

| `database` | `string` | 是 | 要暴露的数据库。 |

<Heading as="h2" id="mongodb">MongoDB</Heading>

加载指定数据库中的集合。可以使用结构化连接字段，也可以提供优先级更高的 `connection`。

```typescript
await ava.source({
  type: 'mongodb',
  options: {
    connection: process.env.MONGODB_URI!,
    database: 'analytics',
  },
```

| 字段 | 类型 | 必填 | 含义与默认值 |
| ----------------------------- | --------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `host` | `string` | 否 | MongoDB 主机名或 IP 地址，默认 `localhost`。 |
| `port` | `number` | 否 | MongoDB 端口号，默认 `27017`。 |
| `database` | `string` | 是 | 包含待加载集合的数据库。 |
| `user` | `string` | 否 | MongoDB 用户名。 |
| `password` | `string` | 否 | MongoDB 密码。 |
| `authSource` | `string` | 否 | 鉴权数据库，对应 MongoDB 的 `authSource`。 |
| `srv` | `boolean` | 否 | 使用 SRV 连接格式，适用于 MongoDB Atlas。 |
| `tls` | `boolean` | 否 | 启用 TLS/SSL 加密，别名为 `ssl`。 |
| `ssl` | `boolean` | 否 | `tls` 的别名。 |
| `tlsCAFile` | `string` | 否 | TLS 的 CA 证书文件路径。 |
| `tlsAllowInvalidCertificates` | `boolean` | 否 | 允许无效证书，仅用于测试，默认 false。 |

<Heading as="h2" id="feishu-bitable">飞书多维表格</Heading>

在 Node.js 的 DuckDB 引擎中使用 `type: 'feishu-bitable'`。记录会暴露为名为 `data` 的只读视图。

首次接入请按[飞书多维表格配置指南](/documentation/data/feishu-bitable/)完成应用创建、权限授权和凭证绑定，指南包含流程示意图、CLI / SDK 示例与常见问题。

```typescript
await ava.source({
  type: 'feishu-bitable',
  options: {
    url: 'https://my.feishu.cn/base/APP_TOKEN?table=TABLE_ID',
    appId: process.env.AVA_FEISHU_APP_ID,
    appSecret: process.env.AVA_FEISHU_APP_SECRET,
  },
});
```

提供 `url`，或同时提供 `appToken` 与 `tableId`，并设置 `appId`、`appSecret`。CLI 也会从 `AVA_FEISHU_APP_ID`、`AVA_FEISHU_APP_SECRET` 或 `~/.ava/feishu.json` 读取凭证。

支持 `/base/` 链接和知识库中的 `/wiki/` 链接。Wiki 链接要求应用具备知识库读取权限并加入相应知识空间，才能解析多维表格。URL 中的 `view` 参数会被忽略。人员、附件、链接、位置、群组等复杂单元格会转换为文本，多个值通常以逗号分隔；公式和查找引用字段按返回值类型转换。

| ------------- | -------- | -------- | --------------------------------------------------------------------------- |
| `accessToken` | `string` | 是 | Supabase Management API OAuth 流程返回的 OAuth 访问令牌。 |
| `projectRef` | `string` | 是 | 项目标识，可从 GET https://api.supabase.com/v1/projects 的结果中获取。 |

<Heading as="h2" id="clickhouse">ClickHouse</Heading>

<Heading as="h3" id="connection-fields">连接字段</Heading>

| 字段 | 类型 | 必填 | 含义与默认值 |
| ---------- | -------- | --------------- | ------------------------------------------------------------------------- |
| `host` | `string` | `host` 或 `url` | 主机名或 host:port；没有协议时，AVA 自动补上 `http://`。 |
| `url` | `string` | `host` 或 `url` | 完整的服务 URL，优先于 `host`。 |
| `port` | `number` | 否 | 覆盖端点中的端口号。 |
| `database` | `string` | 是 | 要发现结构和执行查询的数据库。 |
| `username` | `string` | 否 | 客户端用户名，优先于 `user`；客户端默认值为 `default`。 |

| `password` | `string` | 否 | 客户端密码，默认空字符串。 |

<Heading as="h3" id="forwarded-client-fields">透传的客户端字段</Heading>

`ClickHouseSourceOptions` 也接受以下 `@clickhouse/client` 字段。下表基于已安装客户端的类型声明（1.23.1）；这些字段由该依赖定义，AVA 会在创建客户端时透传。

| 字段 | 类型 | 默认值与含义 |
