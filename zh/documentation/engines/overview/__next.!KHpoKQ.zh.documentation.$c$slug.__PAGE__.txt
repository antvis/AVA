18:Tbf2,# 选择执行引擎

决定数据在哪里加载、查询用什么语言、代码在哪里执行。

import { Heading } from '../../../../mdx-components';

<Heading as="h2" id="engine-selection">选择引擎</Heading>

在 `AVA` 构造函数中设置引擎。JavaScript API 省略该配置时始终选择 DuckDB，不会根据数据源类型自动切换。

| 引擎 | 支持的数据源 | 运行环境 |
| ------------------------------------------------------- | ------------------------------------------------------ | -------------------------- |
| [DuckDB](/documentation/engines/duckdb/) | 内存数据、文件、MySQL、PostgreSQL、SQLite、MongoDB | Node.js |
| [JavaScript](/documentation/engines/javascript/) | 内存 CSV、JSON、文本 | Node.js 和浏览器 |
| [Python](/documentation/engines/python/) | 内存 CSV / JSON；CSV / JSON / Parquet / Excel 文件 | Node.js + Python 执行器 |
| [Supabase](/documentation/engines/remote/#supabase) | Supabase 项目 | Node.js，远程 PostgreSQL |
| [ClickHouse](/documentation/engines/remote/#clickhouse) | ClickHouse 数据库 | Node.js，远程 ClickHouse |

<Heading as="h2" id="engine-configuration">引擎配置</Heading>

| 字段 | 类型 | 必填 | 默认值与行为 |
| ------------- | -------------------------------------------------------------------------------------------- | ------------------------- | --------------------------------- |
| `engine.type` | `'duckdb'` / `'javascript'` / `'python'` / `'supabase'` / `'clickhouse'` / 已注册的名称 | 提供 `engine` 时必填 | 省略 `engine` 时选择 DuckDB。 |

其他字段取决于 `type`，详见 [DuckDB 选项](/documentation/engines/duckdb/#engine-options)和 [Python 选项](/documentation/engines/python/#engine-options)。JavaScript、Supabase、ClickHouse 没有额外的构造函数引擎字段；数据库凭证放在[数据源参数](/documentation/data/sources/#connect-a-source)中。

希望在自己的服务中执行 Python，参见[提供 Python 执行器](/documentation/engines/python/#supply-a-python-executor)。希望在应用中提供自己的引擎，参见[自定义引擎](/documentation/engines/custom/)。

<Heading as="h2" id="shared-contract">共同约定</Heading>

引擎负责加载数据、发现结构、计算统计、根据传入上下文生成查询、执行查询和释放资源。AVA 管理 schema 与 profile 缓存，并决定何时需要发现结构或计算统计信息。

应用通常直接使用 `AVA` API。引擎实现者应遵循[引擎接口约定](/documentation/engines/custom/#engine-contract)，分别实现 `load()` 和 `schema()`。

<Heading as="h2" id="registration">注册</Heading>

Node.js 入口注册全部五种引擎，浏览器入口只注册 JavaScript。注册表让核心 `AVA` 类无需直接依赖各平台专用模块。

扩展 SDK 时，先调用 `registerEngine('sales', SalesEngine)`，再设置 `engine: { type: 'sales' }`。接口约定和完整示例见[自定义引擎](/documentation/engines/custom/)。CLI 仅接受内置引擎名。
