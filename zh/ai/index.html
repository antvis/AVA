预览安装提示词
请在当前项目安装 AVA Agent Skill，让你可以帮我分析数据并生成图表。

1. 检查运行环境：macOS 或 Linux、Node.js 22.13 及以上、npm 可用。如需升级，优先使用已有的 Node 版本管理器；不满足要求时说明缺少什么。
2. 运行 `npm install -g @antv/ava@4` 安装 CLI，并验证 `ava --help` 和 `ava source --help` 可以使用。
3. 运行 `npx --yes skills add antvis/AVA --skill ava --yes`，为当前项目检测到的 Agent 安装 Skill。
4. 阅读安装后的 ava/SKILL.md 及环境配置说明，再用 `npx --yes skills list` 确认安装结果。
5. 在新建临时目录中创建一份很小的 CSV，依次用 `ava source`、`ava schema`、`ava query` 验证数据加载、结构发现和聚合查询。使用实际返回的数据集 ID 和表名，完成后释放测试会话。

分析时请使用你自己的推理能力，不要让我额外配置 AVA 模型 API Key。完成后告诉我 CLI 版本、Skill 位置和验证结果；如有失败，说明实际错误，不要声称已成功。也请说明是否需要开启新的 Agent 会话来加载 Skill。
