了解 AVA，
从这里开始

AVA 是什么？+
AVA 是 AntV 开源的可视分析框架。它给 AI Agent 一套数据工具：接入数据、了解结构、执行分析，再把结果画成图表。
怎么开始使用？+
想先感受一下，可以试试 AI 在线体验。已有 Agent，就接入 AVA Skill；要集成到自己的应用，参照 TypeScript SDK 快速开始。也可以直接用命令行分析数据。
能分析哪些数据？+
支持 CSV、JSON、Excel、Parquet、文本，以及 SQLite、MySQL、PostgreSQL、MongoDB、Supabase、ClickHouse 和飞书多维表格。具体支持范围取决于所选引擎和运行环境。
需要额外申请模型 API Key 吗？+
使用 Agent Skill 时，沿用 Agent 自己的模型，不需要再配一个 Key。通过 SDK 或 CLI 调用 AI 分析能力时，需要配置模型；直接执行查询和查看数据统计则不依赖大模型。
可以免费使用吗？+
可以。AVA 基于 MIT 协议开源，你可以查看源码、集成到项目中，也欢迎参与贡献。使用外部模型或托管服务时，费用由相应服务提供方收取。
