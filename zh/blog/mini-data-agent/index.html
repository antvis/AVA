用 AVA 构建 Mini Data Agent

从一份销售数据开始，让 Agent 分析销售额变化、核对结果，并交付结论和图表。

yvonneyx实践教程2026.11.05

做一个 Data Agent，可以从一个很小的需求开始：给它一份销售数据，让它分析销售额下降主要来自哪些产品，并整理成一份带图表的简短报告。

Data Agent 的核心是由执行结果驱动的分析循环：模型提出查询，读取结果并核对，再决定是否补充分析。要让结论可核查，多次查询需要沿用统一的指标口径，图表也应直接引用实际计算结果。

AVA 是面向 JavaScript 应用和 AI Agent 的开源数据分析框架，旨在连接企业数据，以可信分析与可视化支撑业务决策。类似 Python 生态中的 PandasAI，它支持用自然语言分析数据、生成图表。本文使用 AVA 执行分析与绘图，通过 AI SDK 组织工具调用，构建支持多轮分析与追问的 Mini Data Agent。

准备数据

先准备一份销售订单数据，共 240 笔订单、12 个字段。下面列出前 3 笔订单的日期、产品和销售额：

接着，为 Agent 的分析约定口径：销售额按折后金额统计，月份以下单时间为准，变化额为本期减去上期。把这些约定写入语义配置，供多次查询和后续追问参考。
