# 净销售额与投放决策分析案例

虚构办公用品零售商的多表 SQLite 合成数据，主问题为 **“净销售额下降，要不要加大投放？”**。包含订单、交付、退款、商品与商务条款、广告、流量、库存、采购和市场预算实验，可以从指标核验继续下钻到商品、渠道、市场、门店及采购批次。

数据覆盖 2026-07-06 至 2026-10-18，包含 18 张表、47,171 笔订单、60,866 条商品明细和 278,045 条商品流量记录。默认比较 2026-08-31—09-27 与 2026-08-03—08-30 两个完整四周。金额均为人民币整数分，时间为上海本地时间。

## 文件

| 文件 | 用途 |
| --- | --- |
| `sales-investment.sqlite` | 可直接接入 AVA 的数据源 |
| `semantic.json` | 符合 AVA `Semantic` 类型的语义定义，可通过 `ava.semantic()` 加载 |
| `business-context.md` | 可阅读的业务口径，与语义定义中的规则一致 |
| `question.txt` | 演示起始问题 |
| `schema.sql` | 原始表、外键与索引 |
| `financial-model.sql` | 一行一笔已交付记录的财务模型 SQL；同时写入语义模型的 `refSql` |
| `generate.py` | 固定随机种子的数据生成脚本，会重新生成数据库与语义文件 |
| `build_semantic.py` | 单独重建完整语义文件，无须重新生成数据库 |
| `validate.cjs` | 通过 AVA 加载数据库、保存语义定义、核对 Schema 并执行指标表达式 |
| `verify_data.py` | 用独立的 Decimal 计算核验收入、成本与贡献，并检查完整性、库存及订单金额 |

## 加载语义定义

在应用中创建 `ava` 实例后，先加载数据源，再设置语义定义：

```javascript
const { readFileSync } = require('node:fs');

await ava.source({
  type: 'sqlite',
  options: { path: 'dev-data/sales-investment.sqlite' },
});
const semantic = JSON.parse(readFileSync('dev-data/semantic.json', 'utf8'));
await ava.semantic(undefined, () => semantic);
const result = await ava.analyze('净销售额下降，要不要加大投放？');
```

语义文件包含 18 个原始表模型、1 个 `delivered_sales` 财务派生模型、32 条多对一关系，以及经营财务、广告、商品漏斗、库存流水 4 个 Cube。物理表字段沿用 AVA SQLite Schema 的名称、类型与来源；复合主键以数组声明。

`delivered_sales` 先汇总已完成退款，再按交付计算自营净货款或代销佣金。它保留支付日与交付日两种时间，分别支持支付批次追踪和经营期间复盘。逻辑模型与 Cube **不会自动建表**；直接执行 SQL 时，应将 `refSql` 展开成 CTE 或子查询。

## 可以继续追问

1. 净销售额、支付 GMV 与平台归因销售额的走势一致吗？差别来自哪些业务口径？
2. 按大区、门店、商品、渠道拆解，哪些下降项和增长项解释了整体变化？
3. 是浏览减少、转化下降、缺货，还是退款和商品结构发生了变化？
4. 缺货是否集中在特定商品、门店和日期？预计到货与实际到货有何差异？
5. 退款率异常是否集中在某些采购批次？比较时如何保证退款观察期一致？
6. 平台 ROAS 更高的活动，确认收入与履约后贡献也更高吗？
7. 品牌词预算实验中，实验组所有渠道的订单与贡献发生了什么变化？前期基线和市场间波动是否支持增加预算？
8. 如果决定投放，应优先验证哪些商品、市场与渠道组合？还缺哪些证据？

数据中包含部分履约、多笔部分退款、拒绝退款、平台补贴、历史首购、代销佣金、跨店发货、多活动归因及库存批次等情况。业务表和语义文件不提供原因标签或行动答案；因果判断需要结合实验设计与不确定性。

## 重建与校验

在仓库根目录执行，无须新增依赖：

```sh
# 只修订并重建语义定义
python3 dev-data/build_semantic.py

# 核验原始数据与财务计算
python3 dev-data/verify_data.py

# 用当前仓库 AVA 实现核验加载、语义结构和指标 SQL，无须模型 API
npm run build:cjs
node dev-data/validate.cjs

# 需要重新生成整份数据时执行，会替换本案例数据库与语义文件
python3 dev-data/generate.py
```

这是演示数据，不能用于推断真实企业的投放收益。预算实验只针对特定活动与幅度；观测归因、期间经营贡献及因果增量是不同指标。自然语言分析的实际回答仍需结合所用模型进行验证。
